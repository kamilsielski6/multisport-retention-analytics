# Multisport Retention Analytics

This project analyzes customer retention and churn patterns using synthetic data generated for demonstration purposes.  
The technical stack includes Microsoft Fabric, PySpark, SQL, and Power BI for end‑to‑end data processing and visualization.

## Project Structure

/data-generation      # scripts for synthetic dataset creation  
/notebooks            # exploratory analysis and model development  
/sql                  # SQL queries for data processing  
/docs                 # documentation and diagrams  
README.md             # project overview


## 🎯 Project Objectives

- Generate realistic synthetic data representing customer activity, visits, membership status, and churn behavior.
- Build a scalable data processing pipeline using PySpark in Microsoft Fabric.
- Develop churn prediction models and retention analytics.
- Create interactive Power BI dashboards for business insights.
- Demonstrate best practices for structuring analytics projects in a modern data stack.

---

## 🧱 Tech Stack

- **Microsoft Fabric** — unified analytics environment  
- **PySpark** — distributed data processing and feature engineering  
- **SQL** — data validation and transformation logic  
- **Power BI** — reporting and visualization  
- **GitHub** — version control and project documentation  

---

## 🚀 How to Run (High‑Level)

1. Generate synthetic datasets using scripts in `/data-generation`.
2. Upload data to Microsoft Fabric Lakehouse.
3. Use notebooks in `/notebooks` to process data with PySpark.
4. Run SQL transformations stored in `/sql`.
5. Build Power BI dashboards connected to Fabric.

Detailed instructions will be added as the project evolves.

## 📊 Data Description (Synthetic)

The dataset includes:

- visit logs

All data is synthetic and created solely for demonstration and educational purposes.
